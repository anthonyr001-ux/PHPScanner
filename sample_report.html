PHP lifecycle dates are from php.net's supported-versions schedule. "End of life" means the branch no longer receives security fixes and should be prioritized for upgrade. Version detection relies on headers the server chooses to disclose; a server that hides its version can still be running an outdated PHP, so absence of a version is not evidence of safety. KEV correlation matches CISA's known-exploited catalog by product/vendor; "Likely affected/patched" is a best-effort guess from any version stated in the CVE description and must be confirmed against each host's actual patch level. "Review" means the CVE applies to the product but the version could not be compared.
